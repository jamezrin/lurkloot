Lurkloot is a browser extension. It works in the browser you already use, with the Twitch and Kick accounts you are already signed in to. There is nothing else to download and no Lurkloot account to create.

## Chrome and other Chromium browsers

1. Open [Lurkloot on the Chrome Web Store](https://chromewebstore.google.com/detail/lurkloot/aobaackpofkghaejdnnmpmeaiaoibhdn).
2. Click **Add to Chrome**, then confirm.
3. Pin Lurkloot to the toolbar so the popup is one click away: click the puzzle-piece icon next to the address bar, then the pin next to Lurkloot.

The same Chrome Web Store listing works in **Edge**, **Brave**, **Opera** and **Vivaldi**. Updates install on their own.

## Firefox

Firefox builds are published on [GitHub Releases](https://github.com/jamezrin/lurkloot/releases). They get less testing than the Chrome version, so if something does not work, please [report it](/guide/troubleshooting/report-a-problem).

## What the browser asks for

When you install, the browser lists what Lurkloot can access. It needs Twitch and Kick so it can see your drops, watch streams and claim rewards for you. Lurkloot does not read other sites, does not ask for your password and does not send your activity anywhere. The [privacy policy](/privacy) has the details.

Fortnite and NoPixel rewards are optional. When you turn one of them on, the browser asks for access to that extension's site at that moment, not at install.

## Lurkloot without a browser

If you would rather run Lurkloot on a server, a NAS or an always-on PC, there is also a command-line version that runs in Docker or as a standalone program. It is in beta and works a little differently. See [Extension or CLI?](/guide/getting-started/extension-or-cli).
